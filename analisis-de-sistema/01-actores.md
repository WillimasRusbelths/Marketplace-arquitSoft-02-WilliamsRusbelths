# Actores del marketplace

Los actores son las personas o sistemas externos que interactúan con el marketplace de productos para mascotas.

| Actor | ¿Qué necesita realizar? |
|---|---|
| Cliente | Buscar y consultar productos, agregarlos al carrito, realizar pedidos, efectuar pagos y consultar sus pedidos. |
| Seller | Ofrecer, registrar y actualizar productos; consultar sus productos y gestionar la información de sus ventas. |
| Administrador | Administrar la plataforma y gestionar a los sellers registrados. |
| Pasarela de pago | Procesar los pagos de las compras. |
| Servicio de envío | Gestionar la información de entrega de los pedidos. |
| Servicio de facturación | Generar los comprobantes de pago. |
| ERP | Proporcionar información de productos y stock. |
